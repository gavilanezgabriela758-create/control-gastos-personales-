## Descripción del Sistema
Aplicación desarrollada en Python para la administración de finanzas personales. Permite registrar ingresos y gastos por categoría, calcular saldos en tiempo real y mostrar alertas cuando los gastos superan un límite preestablecido.

## Funcionalidades Principales
1. **Registro de Ingresos:** Almacena montos de ingresos financieros.
2. **Registro de Gastos:** Clasifica gastos por categorías y emite alertas de presupuesto.
3. **Resumen Financiero:** Calcula total de ingresos, gastos y saldo neto disponible.
4. **Historial:** Muestra un registro completo de los movimientos realizados.
